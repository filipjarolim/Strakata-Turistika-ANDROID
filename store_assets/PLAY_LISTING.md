## Kam nahrát v Play Console

1. **Grow → Store presence → Main store listing** (nebo Store listing)
2. Language: **čeština**
3. Short / Full description → vložit texty výše
4. Phone screenshots → nahrát `01`–`04` v tomto pořadí
5. Uložit → odeslat ke kontrole (pokud je draft změny)

Automatický upload z tohoto počítače není nastavený (chybí Play API service account / Fastlane).
